# Index of Multiple Deprivation for MSOAs (2025) in Wales

A data set containing deprivation groups for Middle Super Output Areas
(MSOA) in Wales. The WIMD is calculated at LSOA level. To compare larger
geographies, consider the proportion of small area in a larger geography
which are in the most deprived (say) 10 percent of areas in Wales.This
table provides numbers and percentages of LSOAs within a given local
authority which are in these categories of deprivation: 10percent,
20percent, 30percent, 50percent most deprived overall and for each of
the 8 domains.

## Usage

``` r
imd2025_wales_msoa21
```

## Format

A data frame of class "tbl"

- msoa21_code:

  MSOA code

- domain:

  Domain

- deprivation_group:

  Deprivation group

- data_description:

  Data unit - number or percentage

- data_values:

  Value
